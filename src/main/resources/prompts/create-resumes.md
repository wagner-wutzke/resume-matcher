# Generate Resumes as PDF files

You will generate random Resume files for me.
I need you to be very very creative and not repetitive by this task.

Create 100 Resume files in PDF format.
1. Each candidate has following fields:
- Candidate Name
- Candidate Email
- Country: a LATAM country.
- City: random City in the selected country
- Position: must be one of the following:
    - Java AI Agent Engineer
    - Python Senior Software Engineer
    - Salesforce Senior Developer
    - Java AWS Senior Developer
    - Go Software Developer
    - AWS Cloud Developer
    - Python AI Senior Engineer
    - Principal Software Engineer
    - Lead Software Engineer
    - Backend Software Engineer
    - AI Forward Deployed Engineer
- Skills: at least 10 unique technical skills in the selected Position area (be very creative).
- Working Mode Allocation: Remote, Hybrid, or In-house.
- Expected Salary Range per year: value and currency.

2. All those fields are to be shown in a table format (without header).

3. Each candidate must have 4 to 6 different professional experiences in his/her history.
- Professional experiences must be unique among candidates.
- At least 3 professional experiences must be in the area of the current position.
- A professional experience can be in another random position area (not only one of the the given list).
- Each experience must have specific timeline dates, a random company and activity area in its description.
- Each experience must have 3 to 5 different technical responsibilities.They need to mention related technologies, frameworks and tools (be very creative, verbose and not repetitive).
- Bring all responsibilities under one single header.
- Each experience must have 3 to 5 different achievements descriptions.
  They need to mention related technologies, frameworks and tools (be very creative, verbose and not repetitive).
- The achievements must be handling unique topics in different areas.
- Bring all achievements under one single header.
- The list of professional experiences is to be presented ordered by date: last experience first.
- A list of 0 to 3 Certifications and Courses plus their conclusion dates, related to the professional experiences.

4. The PDF files must have a modern, but simple resume style template layout. No headers or footers.

5. The candidate's name is additionally to be set as document title and shown at the documents top.

6. The PDF files names have the format "[CANDIDATE NAME] - [POSITION].pdf".
