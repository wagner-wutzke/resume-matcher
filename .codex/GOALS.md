# Project purpose

Build a web application that uses AI-powered semantic RAG matching to compare PDF resumes with a job
description and display the three highest-ranked candidates based on matching skills and work
experience.

## Desired outcomes

- A SPA web application which can find matching candidates to a given job description.

## Success conditions

- The Resume PDF's are ingested by the application.
- The Resume PDF's have all the required descriptions (Skills, Work experiences, etc)

## Technical and operational constraints

- The application must have access to a OpenAI ChatGPT account.
- No security is implemented initially.
- Known unknowns or decisions that still require human input.
